🚀 Quick Setup Guide

  1. Get your Google Sheets API Key from Google Cloud Console
  2. Update the API_KEY in config.js
  3. Share your Google Sheet publicly or with the API Key
  4. Ensure the sheet name and data range match your configuration
  5. Open this page in your browser to see the live data

📋 Expected Sheet Format

Your Google Sheet should have the following columns:

Column A Faculty Name
Column B Department
Column C-I Monday through Saturday (class information)
